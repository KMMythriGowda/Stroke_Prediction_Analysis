# Stroke Prediction Analysis using Machine Learning

## Project Overview
This project analyzes healthcare data to predict the likelihood of stroke occurrence using machine learning techniques.

The project includes:
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Machine Learning Model Building
- Model Evaluation

---

## Dataset
Healthcare Stroke Dataset

Features include:
- Age
- BMI
- Hypertension
- Heart Disease
- Smoking Status
- Glucose Level

Target Variable:
- Stroke (0 = No Stroke, 1 = Stroke)

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## Machine Learning Model
Model Used:
- Logistic Regression

Evaluation Metrics:
- Accuracy Score
- Classification Report
- Confusion Matrix

---

## Key Findings
- Older individuals have higher stroke risk
- Hypertension is associated with stroke occurrence
- Dataset is highly imbalanced
